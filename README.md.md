 🎯 1. Descrição do Problema Real
Muitos estudantes, especialmente aqueles em transição de carreira ou de comunidades com menos acesso a ferramentas pagas, enfrentam dificuldades para organizar suas rotinas de estudo. A falta de um método simples de listagem de matérias gera ansiedade e desorganização, o que prejudica o aprendizado.

💡 2. Proposta da Solução
Esta é uma aplicação simples com interface de linha de comando (CLI) que permite ao estudante listar e organizar suas matérias. O objetivo é oferecer uma ferramenta leve, gratuita e funcional para reduzir a dor da desorganização acadêmica.

👥 3. Público-Alvo
Estudantes autônomos, alunos de cursos técnicos e participantes de BootCamp que precisam de uma forma rápida de gerenciar suas prioridades de estudo.
